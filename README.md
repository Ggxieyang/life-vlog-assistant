# 校园生活记录助手 (Life Vlog Assistant)

本项目是一个“端云协同”的校园生活记录工具，只需上传一段视频，系统即可自动生成带情感色彩的 Vlog 文案或生活日记。

## 🎯 核心功能
- **视频自动抽帧**：基于YOLO，自动扫描视频内容。
- **精确目标检测**：使用 YOLOv8n 提取视频中的物体（美食、人物、风景等），解决大模型计数不准的问题。
- **大模型文案生成**：将 YOLO 检测到的结构化 JSON 数据发送给大语言模型，自动生成个性化的校园生活记录。

## 🛠️ 技术架构
- **感知层**：YOLOv8 (Ultralytics) + OpenCV
- **认知层**：多模态大模型 API
- **前端**：Gradio (Web 端，支持手机浏览器访问)

## 🚀 如何运行
1. 安装依赖：`pip install -r requirements.txt`
2. 配置环境变量：`export DASHSCOPE_API_KEY="你的大模型API Key"`
3. 启动应用：`python app.py`
4. 在浏览器中打开本地链接（默认 7860 端口）。
